# Documents

The archive of this organization: what it publishes and what it keeps.

```
documents/
  chronicles/     one chronicle per gathering, with its files
```

Rules:

- Only what the organization publishes lives here. No people's data.
- A text written or filled in by an AI says so, and marks what it assumed with `<!-- NEEDS REVIEW -->` until a person has read it.
- The foundational documents of the organization are in `canon/`, at the root of this repository.
